## 阅读与更新地图

更新时机沿用各文件的维护约定，本表只提供职责与阅读导航。

| 文件 | 职责 | 何时读 |
|---|---|---|
| AGENTS.md | 执行与授权规则 | 接手、实施前 |
| docs/requirements.md | 目标、规则、范围、验收 | 判断范围与行为 |
| TESTING.md | 验证选择、环境和证据规则 | 计划复杂工作、选检查与收尾 |
| 本文件运行章节 | 适用的启动、依赖和基本产品运行恢复 | 启动与环境异常 |
| docs/status.md | 当前任务入口、下一步、人的参与 | 每次接手 |
| docs/tasks/TASK-001.md | 任务执行记录 | 当前任务实施与收尾 |

最小固定职责为本入口、AGENTS、需求、验证和status；任务执行还必须有有界任务记录及必要证据。复杂环境才拆出 development；按实际启用补充 rules、architecture、ux-guidelines、backlog、跨任务阶段计划、decisions 和 experiments 的位置与规则。单任务计划和发布记录在对应 TASK 文件的按需章节维护；跨任务依赖、顺序或阶段检查点复杂时建立阶段计划，任务引用它。版本变化和发布任务索引在 CHANGELOG 维护，共用发布约定在 AGENTS、验证来源和开发运行说明按职责维护。默认不建立总 plan 或 releases 文件。不链接尚未创建的项目记录文件。
